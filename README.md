## Specifications (swedish)

Produkten har följande specifikationer:
- Batteritid som tillåter aktiv inspelning i cirka 8 timmar
- Inspelning i 1080p 30 FPS
- Glasögondel väger 60 g
- Raspberry Pi och powerbank väger 400 g

Produkten består av material med följande kostnader inklusive moms:
- Raspberry Pi 3B+: 499 kr
- InnoMaker 1080P USB 2.0 UVC Camera: 192 kr
- 90-grader mikroUSB-sladd: 91,69 kr
- Linocell Powerbank 10000 mAh: 349,90 kr
- 30 g PLA-filament: ~6 kr
